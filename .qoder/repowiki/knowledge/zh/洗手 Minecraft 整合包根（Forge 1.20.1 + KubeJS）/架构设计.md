根目录是 PCL 管理的 `洗手` 版本根（`.minecraft/versions/洗手/`），各子模块按 Forge 加载顺序协作：`mods_jars` 提供第三方模组 JAR 与 pack.mcmeta；`mod_configs` 通过 defaultconfigs 注入初始配置；`fancymenu_data` 存放 FancyMenu 持久化数据；`kubejs_scripts` 在 startup/server/client 三阶段注册业务逻辑，并通过 `NetworkEvents.dataReceived` 与 `global.*` 全局 API 串联 Pathfinder 泡脚服务、AuraTip 教学状态机与 ApricityUI/KubeJS UI 跨进程通信链；`apricity_ui_assets` 集中 HTML/CSS/图片供客户端加载；`docs` 维护组件级设计文档与 item/relic 知识库作为变更依据。根级产物 `洗手.jar` / `洗手.json` 为打包输出，`hs_err_*` / `replay_pid*` 为 JVM crash dump，`tlm_custom_pack.zip` / `apricity.zip` 为外部资源包。
