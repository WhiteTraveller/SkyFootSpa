本模块为纯静态资源 + 文档的叶子目录，不含可执行代码：
- `apricity/kubejs/` 下按功能划分两类文件：`.html` 为 AUI 页面（泡脚 footui.html / footsoak.html、手机 phone.html、体力 stamina_hud.html、开店 pathfinder_config.html、稀客好感度 rare_affection.html、人物图鉴 character_gallery.html、tooltip.html），配套 `.png/.jpg` 贴图（角色卡片 alice_card.png / reimu_card.png / kaenbyou_rin_card.png 等、按钮 button.png、背景 washi_bg.png / washi_overlay.png / washi_paper.png、图标 reactor.png / magnetama.png / wrench.png 等）。
- `components/apricityui-ui.md` 记录 ApricityUI 1.2.2-hotfix1 / 1.2.4-hotfix 的兼容要点（Rhino 重载歧义、WorldWindow 类路径差异）、容器 Screen 与 Overlay 的差异、鼠标拦截策略、体力同步 API；`components/auratip.md` 记录教学提示系统的客户端 tip 注册、服务端触发器映射、阶段状态 `player.persistentData["aTipTeaching.stage"]` 及命令 `/auratip openshop|reset|debug show`。
依赖方向单向向外：被 `kubejs/client_scripts/ui`、`kubejs/server_scripts/pathfinder` 等运行时脚本引用，自身不反向依赖任何 KubeJS 脚本。
