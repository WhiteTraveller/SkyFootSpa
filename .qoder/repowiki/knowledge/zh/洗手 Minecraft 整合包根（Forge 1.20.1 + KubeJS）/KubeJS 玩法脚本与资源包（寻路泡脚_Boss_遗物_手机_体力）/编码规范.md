- 跨文件共享状态挂载到 `global` 命名空间（如 `global.pathfinderTick`、`global.bossRegister`、`global.pfFootUiClientState`），避免 KubeJS 热重载后多份实例。
- 每个子系统在 `server_scripts/` 和 `startup_scripts/` 下按功能分目录组织（`pathfinder/`、`boss/`、`relic/`、`phone/`、`stamina/`、`recipes/`），并通过 `pf*` / `boss*` 前缀函数暴露接口。
- 可配置实体（Boss、Relic、Oil 等）采用「注册框架 + 链式 DSL」模式：先在 `*Register.js` 中定义 Builder 类并挂到 `global`，再由具体 `boss_*.js` / `oilItem/*.js` 调用 `register(cb => cb.setX(...))` 完成声明式注册。
- 客户端 UI 统一通过 `Java.loadClass` 加载 ApricityUI 类，并使用 `WorldWindow` + HTML 模板（`assets/kubejs/apricity/footui.html`）渲染，状态保存在 `global.pfFootUiClientState` 的 Map 中以 UUID 为键。
- 日志输出统一带 `[MODULE]` 前缀（如 `[PF]`、`[BOSS]`、`[FOOT-UI]`、`[PF-SLEEP]`），便于从 KubeJS 日志中过滤子系统信息。
- 中文本地化资源集中放在 `assets/<mod>/lang/zh_cn.json`，第三方 Mod 文本通过同名文件覆盖，新增内容直接追加而非修改原文件。
