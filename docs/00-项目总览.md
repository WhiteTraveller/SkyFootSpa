# 00 · 项目总览

## 定位

**洗手** 是一款 Minecraft 1.20.1 (Forge) 整合包，风格为 **模拟经营空岛 × 东方Project × 科技线**：

玩家经营一家足浴店，通过给东方Project角色搓脚赚取金钱与声誉，并从中获取基础资源；
在空岛环境下不依赖挖矿，而是以「服务 → 资源 → 科技」的循环逐步解锁五章科技线，
最终建成高度自动化的产线。剧情以主角 **爱丽丝** 为中心，提供 galgame 式对话与流程指引。

## 核心游戏循环

```
顾客生成（按类别权重 + 评价加权）
    │
    ▼
寻路上床 → 躺床（4 部位需求清单生成）
    │
    ▼
玩家搓脚服务（羊毛 / 搓脚手 / 筋膜枪等工具满足需求）
    │
    ├──► 金钱：coinsje 硬币（铜→铁→金→钻石→下界合金，1:9 递进）
    ├──► 声誉：满意度 > 60 → 类别评价 +1（影响后续生成权重）
    └──► 资源：掉落「皴」（基础资源原矿）
              │
              ▼
      皴处理产线（水洗 → 筛分 → 矿粒/煤炭/赛特斯石英）
              │
              ▼
      科技章节推进（解锁更高级机器与配方）
              │
              ▼
      更好的工具与设施 → 服务更多类别顾客 ──（回到循环起点）
```

## 关键模组

| 模组 | 作用 |
| --- | --- |
| Touhou Little Maid | 东方角色模型与实体载体 |
| KubeJS | 全部自定义玩法逻辑（顾客、寻路、搓脚、结算、配方） |
| ApricityUI | HTML 驱动的客户端 UI（脚部交互界面、手机、tooltip） |
| Create + Create Sifter | 第一章科技：初步矿物处理 |
| Immersive Engineering + Immersive Industry | 第二章科技：复杂产线 |
| AE2 / Mekanism | 第三至五章科技（规划中） |
| FTB Quests | 任务与进度指引 |
| Dialog | galgame 式对话（剧情系统） |
