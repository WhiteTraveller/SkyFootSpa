## 一、流体线路 · 三产物（效果与价值由低到高）

### 现状梳理（避免重复）

| 已有 | 特点 | 问题 |
| --- | --- | --- |
| 能量饮料 1/2/3 | 1000/2000/3000，扣血+饥饿 | 有副作用，应急用 |
| 体力药剂 1–5 | 1000→8000，无副作用 | 数值梯度已铺满 |

体力药剂数值梯度已满，**三产物不再堆数值**，走「效率 + 增益 + 稀缺」维度：

### 三产物设计

| # | 产物 | 定位 | 效果 | 价值 | 主要机器 |
| --- | --- | --- | --- | :-: | --- |
| 1 | **清浊饮** | 平价无副作用 | 回 2500，无副作用 | 1x | 基础电解槽 + 灌装机（A 级） |
| 2 | **百草醇** | 恢复 + 增益 | 回 5000 + 急迫/速度 buff 60s | 3x | 发酵机 + 搅拌机 + 灌装机（B 级） |
| 3 | **琼浆** | 顶级 · 带旧地狱材料 | 回 10000 + 再生 II 20s + 饱和 | 9x | 化学反应器 + 灌装机（B 级，批次 5 后） |

### 配方流程（复杂度阶梯）

```
① 清浊饮（批次 2 起，A 级机器即可）
   皴水 1000mb ─基础电解槽→ 净化电解液 500mb
   净化电解液 + 玻璃瓶 ─灌装机→ 清浊饮
   （复用已有电解液概念，皴水杂质电解去除，自洽）

② 百草醇（批次 3 起，需电子元件 → 重型块 → B 级机器）
   植物原料 ─发酵机→ 乙醇
   乙醇 + 精油原料(杂酚油提纯/花瓣) ─搅拌机→ 百草醇原液
   原液 + 玻璃瓶 ─灌装机→ 百草醇

③ 琼浆（批次 5 后，材料含旧地狱专属产出）
   百草醇原液 500mb + 电解质水 250mb + 琼浆引(旧地狱掉落)
       ─化学反应器（催化剂：萤石粉，见固体线新材料）→ 琼浆原液
   原液 + 钢瓶 ─灌装机→ 琼浆
```

- **铁律**：琼浆售价 < 同工时服务收入（08 要点校准基准 2–3 倍）。
- 三产物同时是批次 6 价值阶梯商品的 1x/3x/9x 原型（礼盒装 = 灌装机换容器）。

## 二、固体线路 · 复杂流程与皴高效处理

### 双路并行设计（基础矿物主出口 = 筛矿机，复用第一章基建）

```
皴块 + 水 ─Create搅拌→ 皴水 + 洗净皴块（或皴块直接筛）
                          │
        ┌─────────────────┴─────────────────┐
        ▼（筛矿升级线，基础矿物主出口）        ▼（深加工线，本章新增）
   【Create筛分机】筛网五级阶梯              粉碎机 → 粉碎皴块（本章新增）
   安山→线→黄铜→进阶黄铜（一章已有）           │
        │                                    ▼
   ④钢筛网（批次2：钢线+钢板升级）    ─直接回流筛分机（筛出 2×，稀有矿概率更高）
        │
   ⑤电子筛网（批次4：电子元件升级）
        │
   矿粒+煤炭（主产出）
   + 电子筛网另产红石粉/萤石粉（新材料唯一来源）
```

### 筛网升级阶梯（复用第一章筛矿路线）

| 档位 | 筛网 | 批次 | 升级配方 | 产量 | 概率（铁/铜/锌 · 金/石英） |
| --- | --- | --- | --- | :-: | --- |
| 1–3 | 安山/线/黄铜/进阶黄铜 | 一章已有 | — | 1/1/1.5/2.25× | 40·20 / 40·20 / 60·30 / 90·45 |
| 4 | **钢筛网** | 批次 2 | 进阶黄铜筛网 + 4钢线 + 2钢板 | 3× | 100% · 60% |
| 5 | **电子筛网** | 批次 4 | 钢筛网 + 2电子元件 + 2钢板 | 4× | 100% · 75%，另带**红石粉 25% + 萤石粉 15%** |

- 设计意图：基础矿物出口始终留在第一章的筛矿机，本章产物（钢/电子元件）
  转化为筛网升级材料——**基建保值，升级感来自本章科技**。
- 新材料（红石粉/萤石粉）**唯一来源 = 电子筛网**（批次 4：红石粉 25% + 萤石粉 15%）；
  窑线已全部退出新材料生产（深加工线简化为粉碎机直出粉碎皴块，车窑本章不启用，见下）。
- 煤炭副产（洗净皴块）随筛网档位同步提升（30%→45%→60%→75%），保障炼钢燃料；
  **煤炭粉**为粉碎皴块筛分的专属产物（洗净皴块筛不出），见「粉碎皴块筛分规则」。

### 深加工线核心配方：粉碎皴块直筛（用户拍板简化版）

> 演进记录：原「皴粉+杂酚油→矿砂」车窑方案已随本次简化取消——
> 回转窑经实测只接受纯物品输入；车窑虽支持「物品+流体」混入，
> 但用户拍板深加工线跳过窑处理：粉碎机直接产出「粉碎皴块」，直接进 Create 筛分机。
> 车窑本章不启用，待第三章重新评估。

| 环节 | 配方 | 说明 |
| --- | --- | --- |
| 粉碎 | 洗净皴块 ×1 ─IE粉碎机→ 粉碎皴块 ×1 | 深加工中间品，不经窑处理 |
| 筛分 | 粉碎皴块 + 任意筛网 → 矿粒（产出 2×）+ 煤炭粉（专属） | 直接进 Create 筛分机，共用筛网阶梯，见「粉碎皴块筛分规则」 |
| 矿砂 / 车窑 / 皴粉 | **取消** | 原「皴粉→车窑→矿砂」方案的中间品与机器全部作废，矿砂不注册 |
| 杂酚油消耗口 | **仅剩蒸馏塔** | 车窑退出后，杂酚油由分馏塔消化（见下） |

**回转窑的章节角色**：不变——烧炭（原木 → 木炭 + 杂酚油 250mb，模组自带配方），落在分支 C。

**煤炭粉用途（去向必须明确，否则就是垃圾副产）**：

| 副产物 | 来源 | 用途 |
| --- | --- | --- |
| 煤炭粉 | 粉碎皴块筛分（专属） | 直接燃料（燃烧值同煤炭）/ 焦炭炉进料（2煤炭粉 → 1焦炭 + 杂酚油 250mb，比例待定） |

**新材料用途（去向必须明确，否则就是垃圾副产）**：

| 新材料 | 来源 | 用途 |
| --- | --- | --- |
| 红石粉 | 电子筛网（批次 4，25%） | 电子元件产能扩张（高效版配方材料）+ 自动化元件 |
| 萤石粉 | 电子筛网（批次 4，15%） | 琼浆的催化剂 + 电弧炉助熔剂（星熔钻石提速） |

### 杂酚油分馏支线（蒸馏塔）

```
杂酚油 1000mb ─蒸馏塔→ 石脑油 400mb + 塑料颗粒(固) ×2
```

| 分馏产物 | 去向 |
| --- | --- |
| 石脑油 | 灌装机容器合成 / 柴油发电机燃料（若引入发电教学） |
| 塑料颗粒 | 百草醇/琼浆的瓶盖与包装（礼盒材料） |
| 粗制氨水 | 气体线搁置，暂不产出（待第三章设计气体线时再启用） |

- 原料即焦炭炉副产杂酚油（回转窑烧炭也副产 250mb/次），不再新注册焦油流体；
  蒸馏塔依赖简化为「焦炭炉有产出即可」，不再被窑线卡脖子。

### 粉碎皴块筛分规则（统一去向：筛矿体系）

- 粉碎皴块直接进 Create 筛分机：
  粉碎皴块 + 任意筛网 → 产出为同级筛网筛洗净皴块的 **2×**，
  且金/石英等稀有矿概率上调（钢/电子筛网下更高）。
- 专属产物：只有粉碎皴块能筛出**煤炭粉**（洗净皴块筛不出），
  概率随筛网档位提升（基础档约 40% → 电子筛网约 80%，具体数值待实测）。
- 基础矿物出口因此完全收敛到筛矿升级线一处：
  洗净皴块（基础产率）与粉碎皴块（高产率原料）共用同一套筛网阶梯，
  回转窑的价值 = 烧炭供燃料与杂酚油；深加工线的价值 = 仅粉碎一步即得高产筛矿原料。

### 本章阶段产物（复杂流程终点 = 批次 6 出口钥匙）

```
红石粉 + 萤石粉 + 电子元件 ─装配机（高效配方）→ 强化电子组件（第三章钥匙）
```

- 强化电子组件 = 07 文档「出口关键物品」的具体化：
  它**只能**由电子筛网新材料（红石粉/萤石粉）+ 电子元件合成，
  确保「走完全章复杂流程才能毕业」。

## 开放问题

- 粉碎皴块筛分 2× 产出与煤炭粉概率（40%→80%）的具体数值待实测；
  煤炭粉炼焦的 2:1 比例与杂酚油产量需按焦炭炉节奏校准。
- 钢/电子筛网的产量与概率按 1.5× 阶梯外推（3×/4×），需实测手感。
- 萤石粉若作催化剂消耗过快，琼浆产能会被卡——是否给催化剂不消耗属性。
- 琼浆引（旧地狱专属掉落）的具体命名与掉率，需与批次 5 设计同步。
- 塑料颗粒是否值得做成独立物品，还是直接复用已有包装类物品。
