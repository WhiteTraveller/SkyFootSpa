# 10 · 第二章分支设计与机器复用

> 在 09 两条主线之上增加 6 条可选分支，目标：**机器用满、材料复用、选择多元**。
> 更新时间：2026-08-30。
>
> 分支三原则：
> 1. 每条分支必须**复用至少一个已有节点**（机器/材料/流体），不凭空引入；
> 2. 分支是**替代路线或副产物消化**，主线路径保持最短；
> 3. 分支单位收益不得高于主线（多元 ≠ 捷径）。

## 二、六条分支设计

### 分支 A · 矿渣回收（副产物消化）

高炉炼钢一直副产矿渣，目前无去向。

```
矿渣 ─粉碎机→ 矿渣砂
矿渣砂 + 水 ─搅拌机→ 矿渣浆
矿渣浆 ─金属冲压机(板材模具)→ 矿渣砖（建筑方块）
```

- **复用**：粉碎机、搅拌机、冲压机（全部已有角色），矿渣（免费副产）。
- **去向**：矿渣砖作为旧地狱店铺建材之一（与防腐木并列），并可作出售商品 1x 档填充。

### 分支 B · 植物油路（压榨机入场）

```
油料作物(花生/大豆等) + 水 ─压榨机→ 植物油(复用 fuma_plantoil) + 渣饼
渣饼 ─发酵机→ 乙醇（复用百草醇产线）
```

- **复用**：发酵机（乙醇第二原料）、植物油流体（已注册）。
- **选择**：百草醇的精油溶剂两条来源——杂酚油提纯（固体线副产）vs 植物油（农耕路线），玩家按自己的农场布局选。

### 分支 C · 烧炭路（燃料多元 + 杂酚油副产）

```
原木 ─回转窑(燃烧室加热)→ 木炭 + 杂酚油 250mb（模组自带配方）
```

- **复用**：回转窑（II 0.2.4 自带 rotary_kiln 配方，实测纯物品输入合法）；
  燃烧室（II 单方块，首次启用）；杂酚油回流蒸馏塔分馏/防腐木。
- **选择（燃料三选一）**：焦炭（高炉专用）/ 木炭（通用燃料）/ 石脑油（柴油发电机）。
- 注：II 实际只有回转窑/车窑两种窑，不存在独立「炭窑」机器；烧炭即回转窑的本职配方。

### 分支 D · 坩埚铸造（筛矿产物增值路线）

```
筛矿产物（矿粒/金属锭） ─坩埚熔炉→ 熔融金属液 ─灌装机(模具铸造)→ 锭（可掺净化电解液）
```

- **复用**：筛矿体系的产出、灌装机（饮品灌装与铸造共用一台机器的两种模具概念）、
  净化电解液（清浊饮同源流体）。
- **价值**：净化铸造 +10% 概率双锭；给筛矿产物一条增值深加工路，
  与「粉碎皴块直接筛分」互补（筛分求量，铸造求质）。

### 分支 G · 金属容器（冲压机新模具）

```
钢板 ─金属冲压机(容器模具)→ 钢瓶（琼浆容器）
```

- **复用**：冲压机、钢（关键锭消耗口）。
- **选择（容器二选一）**：玻璃瓶（清浊饮/百草醇，廉价）/ 钢瓶（琼浆，高级感+钢消耗水槽）。
- 密封罐随气体线搁置，第三章罐装需求出现时再加。

### 分支 H · 木屑乙醇（锯木机入场）

```
原木 ─锯木机→ 木板 + 木屑
木屑 ─发酵机→ 乙醇
```

- **复用**：发酵机（乙醇第三原料）、木板（旧地狱店铺建材）。
- **定位**：乙醇量产的兜底路线（不依赖农场），同时把锯木机接进本章。

## 三、多元选择矩阵（玩家视角）

| 需求 | 可选路线 |
| --- | --- |
| 出矿（基础矿物） | 筛矿升级线：安山→线→黄铜→进阶黄铜→**钢筛网**（批次 2）→**电子筛网**（批次 4，另带红石/萤石粉）；粉碎皴块（粉碎机直出）直接进同一筛分机（产出 2×，稀有矿概率更高，专属产煤炭粉）。主出口唯一：Create 筛分机 |
| 新材料（红石/萤石粉） | 电子筛网唯一来源（批次 4：红石粉 25% + 萤石粉 15%）；窑线经实测不产新材料 |
| 燃料 | 焦炭 / 木炭 / 石脑油 / 煤炭粉（深加工专属，可炼焦） |
| 乙醇 | 植物原料 / 渣饼 / 木屑 |
| 精油溶剂 | 杂酚油提纯 / 植物油 |
| 饮品容器 | 玻璃瓶 / 钢瓶 |
| 建材 | 防腐木（杂酚油）/ 矿渣砖 / 木板 |

**设计意图**：同一目标 ≥ 2 条路线，且路线间消耗不同的上游材料，
玩家的工厂布局决定路线选择，而不是单纯比数值。

## 六、发电问题的收束（回应 08 开放问题）

本章电力来源定为**按需自然引入**：
- 前期单机电直接拉线即可（IE 发电机可不做）；
- 分馏石脑油 → 柴油发电机，
  作为「自动化规模上量后的第一台发电设施」，自然过渡到第三章电力规模化。
