## 一、当前目标设计的关键要素

从当前设计意图中提炼出 5 个核心要素：

### 1. 维度扩展：旧地狱

- 第二章解锁前往**旧地狱**维度的方式。
- 旧地狱会为玩家**生成新的店铺建筑**，可在此维度独立经营。
- 旧地狱顾客：**要求更高**（需更好的工具/体力/服务），**产出物资不同**（区别于主世界）。
- 本质：用「第二店铺」把经营面扩到双维度，形成主世界 + 旧地狱两条经营线。

### 2. 三线产线架构（渐进解锁）

| 线路 | 职责 | 第二章状态 |
| --- | --- | --- |
| 固体线 | 处理皴，产出本章关键锭/电路板 | ✅ 主线 |
| 流体线 | 回体力道具 + 高价值出售物 | ✅ 副线 |
| 气体线 | （气体处理） | 🔒 第三章解锁 |

- 固体与流体线**紧密相连**（共享中间产物），但**目标独立**。

### 3. 双关键物品体系（章节递进核心）

| 章 | 关键锭 | 关键电路板 |
| --- | --- | --- |
| 第一章 | 黄铜 | 精密构件 |
| 第二章 | **钢** | **电子元件** |

- **关键锭** = 本章许多物品的必备材料（硬件门槛）。
- **关键电路板** = 本章更进一步生产的关键材料（进阶门槛）。
- **关键电路板** 同时解锁本章背包遗物（芯片）的制作。

### 4. 芯片经济与效率迭代

- 芯片**需求量巨大** → 需要解锁**更高效的芯片配方**。
- 「更高效配方」本身是进度奖励：做出更好的机器 → 更复杂的处理 → 解锁下阶段关键物品。
- 形成「机器升级 → 效率提升 → 产能放大」的正循环。

### 5. 流体线的独立目标

- 主目标：制作**更好的回体力道具**。
- 附带：设计**出售物品机制**，产出**价值更高的产物**。
- 原则：**价值越高，制作工艺越复杂**（价值阶梯）。

## 二、市面成熟设计参照

| 设计模式 | 代表作 | 核心思想 | 对本游戏的借鉴 |
| --- | --- | --- | --- |
| 关键物品门槛 | GregTech / Create:A&B | 用特定物品作为进度闸门 | 已在用（钢/电子元件），保留双轨制 |
| 削减无意义重复 | Nomifactory | 去掉无回报的微操合成 | 直接呼应「不要太多重复操作」 |
| 自动化里程碑 | Create | 每台机器=一个可见里程碑 | IE 多方块天然契合 |
| 副产物循环 | GregTech byproducts | 副产物回流其他产线 | 皴水 → 流体线（已存在） |
| 价值阶梯 | 交易类模组 | 价值越高工艺越复杂 | 流体线出售物分级 |
| 资源水槽 | 经济类整合包 | 大额消耗防货币溢出 | 芯片巨大需求 |
| 并行分支+汇聚 | FTB 任务流 | 多线汇聚到关键物品 | 固/流体线汇聚 |

**核心成熟经验**：玩家讨厌的不是「复杂」，而是「无意义的重复」。
复杂度带来乐趣，重复带来痛苦。设计要把复杂度花在**有意义的里程碑**上，
而不是让玩家反复手搓大量中间品。

## 三、符合本游戏的设计要点（可执行）

### 要点 1：关键物品双轨制，职责清晰

- **钢 = 硬件轨**：门槛在本章机器/结构/工具的制造上。
- **电子元件 = 智能轨**：门槛在进阶配方 + 芯片制作上。
- 任务树并行呈现两条里程碑，让玩家明确「先炼钢，再制芯」。

### 要点 2：反重复——用「机器里程碑」替代「批量手搓」

- 固体线每个环节收敛为一个 IE 多方块/机器里程碑
  （高炉 → 辊压机 → 装配台 → 化学反应器），
  避免「手搓 64 个中间品才能做 1 台机器」的长链。
- 每个里程碑控制在 1–2 屏合成步骤内，完成后给出**可见回报**（新配方/新任务解锁）。

### 要点 3：流体线 = 经济支线，建立价值阶梯

- 回体力道具（消耗品）与出售物（货币物）构成**收入侧**。
- 出售物分级：价值 1x / 3x / 9x，越高阶配方复杂度指数上升。
- **铁律**：出售物收益不能碾压「服务顾客」这一主收入，是补充而非替代。
- 售价曲线可复用 SDMShop 已有的阶梯价格配置。

### 要点 4：芯片水槽采用两段式配方

- 前期：手工/高成本配方（保证首个芯片的获取成就感）。
- 后期：解锁自动化/低成本高效配方（由电子元件/钢门槛）。
- 原则：**效率本身即奖励**——推进进度换来「效率」，比直接给物品更上头。

### 要点 5：旧地狱用「更高要求」做天然门槛

- 旧地狱顾客要求更高 → 倒逼玩家升级工具/体力 → 自然拉动流体线与关键物品。
- 产出不同 → 与本章特定资源绑定，形成「旧地狱顾客才掉 X」。
- 建议：旧地狱产出物作为**第三章专属中间品**，形成对下章的拉力。

### 要点 6：固/流体线保持耦合

- 固体线的皴水/泡脚水是流体线原料，维持「一个工厂」的整体感。
- 避免两条线变成完全割裂的孤岛。

### 要点 7：章节衔接用关键物品做拉力

- 第二章的最终高价值产物/电路板 = 解锁第三章的关键。
- 气体线在第三章解锁 → 可在第二章埋下伏笔
  （如产出的「压缩气体罐」在第二章暂无用途，第三章才启用）。

## 开放问题

- 旧地狱维度的进入方式（传送门配方/剧情触发）尚未定义。
- 旧地狱店铺建筑的结构模板与生成机制（是否复用空岛 builder）待定。
- 出售机制的具体载体（商店方块？手机下单？）与结算货币待定。
- 气体线（第三章）与固/流体线的衔接点需提前预留接口。
- 钢/电子元件之外，本章是否还需第三关键物（如「钢线圈」作为线缆门槛）待评估。
