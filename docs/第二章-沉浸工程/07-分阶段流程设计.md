> 将第二章拆为 **6 个批次**。入口/出口方式暂留占位，不影响批次内容设计。
> 更新时间：2026-08-29。
>

```

        │

        ▼                      ▼

        │                      │

                   ▼

                   ▼

```

## 批次 1 · 黑金之基（固体线前半段）

**目标**：产出本章关键锭 = 钢。
**前置**：第一章毕业（黄铜筛网、精密构件、皴量产）。

| 里程碑 | 状态 | 说明 |
| --- | --- | --- |
| 皴水洗 / 筛矿 / 煤炭 | ✅ | 现有配方，煤炭是炼焦原料 |
| 焦炭炉（IE 多方块） | 🆕 | 煤炭 → 焦炭 + **杂酚油**（首个流体副产物） |
| 高炉（IE 多方块） | ✅ 配方已有 | 焦炭 + 铁锭 → 钢锭 |

**关键设计**：
- 焦炭炉是本章第一个新多方块里程碑，其副产物**杂酚油**是流体线的第一个原料入口（批次 3 使用），落地「副产物循环」要点。
- 杂酚油同时是 IE 防腐木的原料 → 可用于旧地狱店铺建材，经营与科技互相引用。

**验收**：任务树完成「焦炭出炉」「淬火成钢（已有）」两节点；杂酚油入桶可取。

---

## 批次 2 · 钢结构与机器扩张（硬件轨）

**目标**：以钢为门槛，铺开本章机器集前半段；下界之星开始消耗。
**前置**：批次 1（钢锭）。

| 里程碑 | 状态 | 说明 |
| --- | --- | --- |
| 钢线圈 / 钢线 / 钢板（辊压+切割） | ✅ 已有 | 钢的初加工 |
| 电弧炉（IE 多方块） | 🆕 | 承载「星熔钻石」配方（见下） |

**关键设计**：
1. **星熔钻石**（经营奖励的消耗口）：
   电弧炉配方：`下界之星 + 4×煤炭块 → 2×钻石`。
   - 下界之星来自高满意度奖励（经营系统），此前无消耗出口，容易囤积。
   - 钻石作为稀有储备材料，供后续批次/第三章高价值配方消耗。
   - 主题自洽：碳 + 能量 → 钻石。
2. 机器集**按需解锁**：本批次只开电弧炉，其余机器（装配台已有）随批次 3/4 逐个开，避免一次性放太多机器造成选择瘫痪。
3. 化学反应器不在本批次：钻石块结构门槛已作废（仅为魔改可行性测试），
   化学反应器归位为常规 B 级机器，随批次 4（重型工程块）解锁。

**验收**：电弧炉搭建成功，跑通星熔钻石配方，钻石入库。

## 批次 3 · 流体线（体力与服务耗材）

**目标**：回体力道具品质升级 + 建立服务耗材品类。
**前置**：批次 1（杂酚油、皴水）+ 化学反应器（批次 2）。

**核心原则：品质升级而非数值堆砌**——高阶体力药不是「数值更大」，
而是「去掉副作用 + 附加效果」：

| 档位 | 现状/设计 | 状态 |
| --- | --- | --- |
| 能量饮料 1/2/3 | 回 1000/2000/3000，扣生命 + 饥饿（副作用） | ✅ 已有 |
| 精制饮 | 中量恢复，**无副作用**（化学反应器净化） | 🆕 |
| 特调「不老泉」 | 恢复 + 增益 buff（急迫/再生等） | 🆕 |
| 泡脚药包/精油 | 加入泡脚水 → 提升满意度/小费 | 🆕 |

**配方原料入口**（体现固流体耦合）：
- 皴水（固体线副产物）→ 精制饮基础液
- 杂酚油（焦炭炉副产物）→ 精油溶剂
- 旧地狱产出（批次 5）→ 特调饮稀有材料（此处先留接口）

**关键设计**：
- 泡脚药包/精油直接服务经营循环：顾客满意度↑ → 评价↑ + 下界之星↑ → 反哺批次 2 的星熔钻石。流体线由此**闭合回经营**，不只是独立支线。
- 旧地狱高要求顾客（批次 5）要求玩家常备精制饮以上，形成消耗刚需。

**验收**：三档新流体产品可生产；泡脚药包在泡脚系统中生效。

## 批次 4 · 智能轨（电子元件与芯片）

**目标**：关键电路板 = 电子元件落地为进度门槛，解锁本章背包遗物（芯片）。
**前置**：批次 2（钢线）+ 第一章精密构件。

| 里程碑 | 状态 | 说明 |
| --- | --- | --- |
| 电子元件（装配台蓝图） | ✅ | 2精密构件+4钢线+2红石+1铁板 |
| 芯片 stage2 手工配方 | 🆕 | 电子元件 + 钢 + 稀有材料 → 芯片（贵，1:1） |
| 芯片高效配方 | 🆕 | 装配台/化学反应器批量版（1:2 或返还材料） |

**关键设计**：
1. **两段式芯片配方**（落地「效率即奖励」要点）：
   - 手工版保证首个芯片的仪式感与稀缺性；
   - 高效版作为**任务/成就奖励解锁**（而非合成发现），让「推进进度换效率」被明确感知。
2. 电子元件同时是批次 6 出口关键物品的原料（见批次 6）。

**验收**：两版芯片配方均可跑通；stage2 芯片可装入背包遗物槽生效。

## 批次 5 · 旧地狱扩张（经营侧）

**目标**：第二店铺上线，经营面扩到双维度。
**前置**：批次 3（体力刚需品）+ 批次 4（工具升级材料）。
**入口方式**：暂留占位（任务解锁点预留，具体传送机制后定）。

| 内容 | 状态 | 说明 |
| --- | --- | --- |
| 旧地狱店铺建筑生成 | 🆕 | 结构模板 + 生成机制待定 |
| **鬼族顾客解锁** | 🆕 | `oni` 类别激活——旧地狱正是东方设定中鬼族聚居地（萃香、勇仪） |
| 高要求顾客机制 | 🆕 | 需求数更多/工具等级要求更高 |
| 旧地狱专属产出 | 🆕 | 区别于主世界的结算掉落 |

**关键设计**：
1. **鬼族解锁是现成的**：`pfCustomerTypes.js` 已预留 `oni` 类别（16 个模型），
   在旧地狱激活即可，主题与原作完全吻合，零新增资产。
2. 专属产出绑定第三章：设计为第三章关键物品的专属中间品，
   形成「只有旧地狱顾客才掉 → 想做第三章必须开旧地狱店」的拉力。
3. 高要求 = 批次 3 体力药、批次 4 钢制工具的天然消耗口。

**验收**：旧地狱店内鬼族顾客正常生成/寻路/躺床/结算；专属掉落入包。

## 批次 6 · 出售机制与章节出口

**目标**：建立出售经济；产出第三章钥匙。
**前置**：批次 3 + 批次 4。

| 内容 | 状态 | 说明 |
| --- | --- | --- |
| 出售机制载体 | 暂留占位 | 建议复用 SDMShop 阶梯价格，载体（商店方块/手机）后定 |
| 价值阶梯商品 | 🆕 | 1x/3x/9x 三档，越高档配方越复杂 |
| 出口关键物品 | 🆕 | 电子元件衍生高阶品（名称待定），第三章关键物品的前置 |

**价值阶梯示例**（全部复用本章原料，无新增资源入口）：

| 档位 | 商品示例 | 配方复杂度 |
| --- | --- | --- |
| 1x | 精制泡脚液（桶装） | 流体直灌 |
| 3x | 精油礼盒 | 流体 + 固体材料组装 |
| 9x | 「不老泉」礼装 | 特调饮 + 电子元件 + 钢制容器 |

**铁律**（来自 06 要点 3）：出售总收益不得碾压服务顾客的主收入——
数值校准基准：单局服务收入 ≈ 同工时出售收入的 2–3 倍。

**验收**：三档商品可出售回款；出口物品合成后在任务树点亮第三章入口。

## 批次推进节奏建议

| 批次 | 预估定位 | 玩家主要动作 |
| --- | --- | --- |
| 1 | 快速热身 | 搭两个多方块，拿到钢 |
| 2 | 投资期 | 攒下界之星换钻石，建化学反应器 |
| 3 | 创造期 | 调配新饮品，接回经营循环 |
| 4 | 解锁期 | 芯片两段式，体验「效率奖励」 |
| 5 | 扩张期 | 开新店，接待鬼族 |
| 6 | 收尾期 | 出售回款，毕业出口 |

批次 1–2 是硬件门槛（钢），批次 3–4 可并行（流体/智能双线），
批次 5 需要 3+4 的产品支撑，批次 6 收束全章——
符合 06 要点 1「先炼钢，再制芯」与要点 7「关键物品做章节拉力」。

## 开放问题

- 特调「不老泉」的 buff 选型与时长（避免过强破坏经营节奏）。
- 高效芯片配方的具体增益形式（1:2 产出 vs 返还材料）需数值测试。
- 旧地狱专属产出的具体物品清单（需与第三章设计同步）。
- 出口关键物品命名与形态（是否为「进阶电路板」需与第三章关键物品一起定）。
