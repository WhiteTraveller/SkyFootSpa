## 二、两级机器体系（轻/重型工程块）

### 分级原则

| 级别 | 结构核心 | 解锁条件 | 定位 |
| --- | --- | --- | --- |
| A 级 · 简单 | 轻型工程块 + 砖块/钢板等杂项 | 钢产出后即可（批次 1–2） | 基础加工：压板、拉线、粉碎、初炼 |
| B 级 · 复杂 | 重型工程块（+高价值投资件） | **关键电路板 = 电子元件**（批次 4） | 精加工：更好的饮品、皴深加工、第三章钥匙 |

### A 级机器（本章前半段解锁）

| 机器 | 用途（对第二章） |
| --- | --- |
| 焦炭炉 | 批次 1：焦炭 + 杂酚油 |
| 高炉 / 改良高炉 | 批次 1：钢锭 |
| 金属冲压机 | 批次 2：钢板/齿轮/棒 |
| 粉碎机 | 矿粒粉碎、皴块预处理 |
| 锯木机 | 建材（旧地狱店铺） |

### B 级机器（电子元件解锁后）

| 机器 | 用途（对第二章） |
| --- | --- |
| 搅拌机 | 批次 3：精制饮 / 泡脚药液调配 |

| 灌装机 | 批次 3/6：饮品与礼盒灌装 |

| 装配机 | 批次 4：芯片高效配方 |

| 回转窑 | 分支 C：原木 → 木炭+杂酚油（自带配方） |

## 三、工程块配方改造（门槛设计核心）

**原版配方**（实测自模组）：

| 方块 | 原版配方（产出 4） |
| --- | --- |
| 轻型工程块 | 铁板钣金 ×4 + 铜锭 ×1 + 铁构件 ×1 |
| 重型工程块 | 钢板钣金 ×4 + 金银合金锭 ×1 + 钢构件 ×1 |

原版重型块只要金银合金（铜+金电弧合金），**没有智能门槛**，
玩家炼出钢就能一路冲到 B 级机器——不符合「电子元件解锁难机器」的要求。

**改造方案（数据包覆盖配方）**：

```
重型工程块（改后，产出 2）：
    轻 轻 轻
    轻 芯 轻      芯 = 电子元件（关键电路板）
    轻 轻 轻      轻 = 轻型工程块
```

- 轻型工程块**保持不变**（铜+铁门槛，批次 2 自然达成）。
- 重型工程块改为 **8×轻型工程块 + 1×电子元件 → 2 重型**。
- 效果链条：电子元件（批次 4）→ 重型工程块 → B 级机器 →
  更好的饮品 / 皴深加工 / 第三章解锁物品。
- 产出从 4 降为 2，配合 B 级机器每台 4–12 个重型块的用量，
  形成「电子元件产能 = B 级机器扩张速度」的节奏阀门。

**化学反应器的门槛（✅ 已定稿）**：钻石块结构门槛已作废（仅为魔改可行性测试，
用户确认不启用）。化学反应器归位为**常规 B 级机器**：
门槛 = 重型工程块 = 电子元件，与搅拌机/发酵机/装配机等同级。
重型工程块（常态智能门槛）独立承担「电子元件解锁难机器」的职责。

## 四、与 07 批次设计的映射

```
批次1（钢）──► 轻型工程块 ──► A级机器：冲压/粉碎/焦炭/高炉/电弧炉（星熔钻石）
批次4（电子元件）──► 重型工程块 ──► B级机器：搅拌/发酵/装配/化学反应器…
                                      │
                                      ├─► 更好的饮品（批次3 升级部分）
                                      ├─► 皴进一步处理（粉碎皴块直筛/电解）
                                      └─► 第三章解锁物品（批次6 出口）
```

注意：07 文档中批次 3 的「精制饮/不老泉」若全部依赖化学反应器，
门槛会偏高；建议**搅拌机型饮品随批次 3 先行**（A→B 过渡），
**化学反应器型特调留到电子元件解锁后**，让批次 3 也有平滑起点。

  建议电弧炉仍用轻型结构（保持 A 级），仅配方产出钻石供化学反应器投资。
