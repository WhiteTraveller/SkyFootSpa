# 02 · 空岛 · 资源循环系统

> 空岛玩法核心：**不挖矿**。所有基础资源来自经营玩法与特色机制，
> 再经由产线加工为科技线所需材料。

## 资源获取途径

| 途径 | 产出 | 说明 |
| --- | --- | --- |
| 搓脚结算掉落 | 皴块（`marguerite:cun_block`） | 核心资源原矿，随服务结算掉落；一键满足按总清零次数结算 |
| 高满意度奖励 | 下界之星 | 满意度 > 60 时额外掉落 |
| 金钱购买 | 各类商品 | 硬币经济（见 01 文档） |
| 其他特色机制 | 草灰、电解液等 | 空岛替代获取路径（配方见 `recipes/` 目录） |

## 皴处理产线（第一章 → 第二章）

皴块是资源循环的枢纽，加工链如下：

```
皴块
 ├─ ① 动力搅拌（不加热）：皴块 + 水(1000mb)
 │        → 皴水(1000mb) + 洗净的皴块
 │
 ├─ ② 洗净的皴块 → 黄铜/进阶黄铜筛网（Create Sifter）
 │        → 矿粒（铁/铜/锌/金）+ 石英 + 煤炭(30%/45%)
 │
 └─ ③ 皴水(8000mb) → 动力搅拌（加热）
          → 赛特斯石英（AE2 前置材料，远期伏笔）
```

- 筛网分级：黄铜筛网 ×1.50 倍率、进阶黄铜筛网 ×2.25 倍率；线筛网不可筛洗净皴块。
- 实现：`kubejs/server_scripts/recipes/recipes_cun_processing.js`（第二章产线）。

## 设计原则

1. **服务即采矿**：搓脚次数 / 质量直接决定资源吞吐，经营与科技强绑定。
2. **副产物梯度**：一条产线同时产出多种材料（矿粒/煤炭/石英），避免单点瓶颈。
3. **远期伏笔前置**：赛特斯石英在第一/二章即可微量获得，为 AE2 章节铺垫。
4. **回收闭环**：洗脚废水有拦截与回收机制，避免资源白丢。
