# 03 · 东方Project · 剧情系统

> 东方元素的双重承载：**顾客皆为东方角色**（见 01 文档），
> 以及以主角 **爱丽丝** 为核心的剧情线。

## 主角：爱丽丝

- 剧情的主视角与流程引导者。
- 玩家开店、升级、推进科技章节的节点均由爱丽丝的剧情串联。

## 对话系统

- 采用支持 **galgame 式对话** 的模组（Dialog），提供立绘 + 选项 + 分支文本。
- 序章对话已配置（Skyfootspa 序章），作为新玩家的教学与世界观引入。
- 剧情同时承担「任务指引」职责：告诉玩家下一步该做什么（与 FTB Quests 配合）。

## 角色资产

- 顾客模型：`touhou_little_maid` 模组模型库（100+ 东方角色），
  在 `pfCustomerTypes.js` 中按种族分组。
- 立绘资产：`apricity/kubejs/` 下的立绘与图片资源（如海报、壁纸等），
  经 ApricityUI 展示。
- 十二时辰等东方世界观映射用于店内氛围（时间系统）。

## 剧情与玩法的交汇点

| 节点 | 剧情职责 | 玩法职责 |
| --- | --- | --- |
| 序章 | 引入开店背景 | 教学：接待第一位顾客 |
| 章节解锁 | 爱丽丝引导科技方向 | 解锁 Create → IE → … 产线 |
| 新顾客类别 | 种族相关的支线剧情 | 解锁鬼族 / 月球类别（预留） |
