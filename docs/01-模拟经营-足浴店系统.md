# 01 · 模拟经营 · 足浴店系统

> 经营目标：**赚钱** 与 **获取声誉**。顾客为东方Project角色，按种族分类。

## 顾客分类

顾客分为 5 个类别（基于 `touhou_little_maid` 模型），通过活跃类别列表控制生成：

| 类别 | 名称 | 代表角色 | 当前状态 |
| --- | --- | --- | --- |
| `ningen` | 普通 | 雾雨魔理沙、十六夜咲夜、东风谷早苗… | ✅ 活跃 |
| `youkai` | 妖 | 琪露诺、蕾米莉亚、八云紫、风见幽香… | ✅ 活跃 |
| `kami` | 神 | 八意永琳、八坂神奈子、纯狐… | ✅ 活跃 |
| `oni` | 鬼族 | 伊吹萃香、古明地觉、茨木华扇… | 🔒 保留（不生成） |
| `tsukikou` | 月球 | 绵月丰姬、稀神探女、铃仙… | 🔒 保留（不生成） |

> 保留类别的数据完整存在，仅不出现在生成池——用于后续章节 / 声誉解锁。
> 实现：`kubejs/server_scripts/pathfinder/pfCustomerTypes.js` 的 `PF_ACTIVE_CATEGORIES`。

## 评价与权重系统（声誉）

- 每类顾客独立持有评价值（0–100），存储于玩家 `persistentData`。
- 满意度达到 **60** 时，该类别评价 +1。
- 生成采用加权抽取：总池 10000，每类权重 = `400 + 评价值 × 5`。
- 评价越高 → 该类顾客出现越频繁，形成「服务好 → 回头客多」的正循环。

## 服务流程

```
顾客按权重抽取生成
    │
    ▼
寻路至空闲床位（pathfinder 模块，蓝色地毯约束）
    │
    ▼
躺床 → 生成 4 部位需求清单（脚掌 / 脚后跟 / 脚趾 / 脚心）
    │
    ▼
玩家搓脚服务
    ├─ 工具：羊毛（基础）→ 搓脚手 → 筋膜枪（高级）
    └─ 需求部位与工具部位需匹配
    │
    ▼
需求全部满足 → 结算
    ├─ 掉落硬币（金钱）
    ├─ 掉落「皴」（资源，详见 02 文档）
    └─ 高满意度（>60）额外奖励：下界之星 ×1
    │
    ▼
顾客离店（玩家也可主动「送客」：不结算、无奖励）
```

## 体力系统

玩家服务消耗体力；体力通过泡脚（泡脚水）、电解质水等恢复——体力是每日接待量的软上限，
构成经营节奏。详见体力系统相关脚本与 `footsoak.html` 泡脚 UI。
