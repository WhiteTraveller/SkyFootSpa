## 第三章 · 石油分馏（进行中）

以 **机械动力：柴油发电机**（`createdieselgenerators`，下称 CDG）为核心，
围绕「石油」构建分馏产线。石油来源承接经营玩法：**鬼族（oni）顾客**泡脚
产出「含油洗脚水」，再经 CDG **分馏塔**提炼出原油。

> 剧情设定：石油即旧地狱血池中「被诅咒的血液」，鬼族当年在此劳作被腌入味，
> 如今从脚上重新搓下（对话见 `kubejs/data/skyfootspa/chatbox/dialogues/story_rin.json` 的 `ch3_rin`）。

### 已实装：含油洗脚水 → 原油

- **含油洗脚水**（`kubejs:oil_foot_water`）：鬼族顾客泡脚结算时，工作盆产物槽生成的废水变体。
  - 分流逻辑：`kubejs/server_scripts/pathfinder/pfBasinSoakManager.js` 的 `OIL_CUSTOMER_CATEGORIES = ['oni']`
    （与 `foot_water` 人类/神明、`fuma_foot_water` 妖怪/妖精并列的第三种废水）。
  - 流体注册：`kubejs/startup_scripts/fluid/soakwater/usedFootWater.js`；
    forge 流体 tag：`kubejs/data/forge/tags/fluids/oil_foot_water.json`。
  - **刻意不并入** `#kubejs:foot_water_bucket`（煮盐配方）——含油洗脚水是本章宝贵资源，不应被通用废水煮盐消耗。
- **分馏配方**：`kubejs/server_scripts/recipes/recipes_chapter3_oil.js`
  - `createdieselgenerators:distillation`（分馏塔，`heated`）：
    含油洗脚水 1000mb → 洗脚水(`kubejs:foot_water`) 1000mb + 原油(`createdieselgenerators:crude_oil`) 100mb。
  - 分馏塔为多方块：需 ≥2 层塔体（对应 2 种产物）+ 底部燃烧室供热。
- **石油 = CDG 原油**：复用 `createdieselgenerators:crude_oil`，可直接接 CDG 自带
  「原油 →(分馏)→ 柴油 + 汽油」二级链，无需额外注册流体。
- **FTB 任务**：第三章章节 `config/ftbquests/quests/chapters/0A0A9CCF5B44C429.snbt`
  已铺 5 节点链：火焰猫燐的来访 → 泛油黑水（含油洗脚水）→ 分馏塔 → 黑金之源（原油）→ 燃料初成（柴油）。

### 已实装：魔力金属产线（第三章下半段）

承接**第二章产物「魔力粉」**（`marguerite:magic_dust`），用剩余的沉浸工程 / 沉浸工业 /
机械动力：电气时代机器，做出一条通往「超高热值燃料」的重工业升级线。核心目标是产出
**充能魔力块**——既是「最强磁铁」，又是 IE 高炉的超高热值燃料。

**主链**（配方见 `kubejs/server_scripts/recipes/recipes_chapter3_magic_line.js`）：

| 步骤 | 机器 | 配方类型 | 输入 → 输出 |
| --- | --- | --- | --- |
| ① | 沉浸工业·回转窑 | `immersiveindustry:rotary_kiln` | 魔力粉 → 魔力锭 |
| ② | 电气时代·激发器（充能） | `create_new_age:energising` | 魔力锭 →(20000 FE)→ 充能魔力锭 |
| ③ | IE·金属冲压机（板材模具） | `immersiveengineering:metal_press` | 充能魔力锭 → 充能魔力锭板 |
| ④ | 工作台 | `crafting_shaped` | 充能魔力锭板 ×8 + 重型工程块 → 重型机械方块 |
| ⑤ | 沉浸工业·车窑 | `immersiveindustry:car_kiln` | 充能魔力锭板 ×9 → 充能魔力块 |
| ⑥ | IE·高炉燃料 | `immersiveengineering:blast_furnace_fuel` | 充能魔力块 = 燃料（time 24000，焦煤 20 倍）|

**新增注册内容**：

- 物品：`marguerite:magic_ingot`（魔力锭）、`energized_magic_ingot`（充能魔力锭）、
  `energized_magic_plate`（充能魔力锭板），见 `kubejs/startup_scripts/item/magic_ingots.js`。
- 方块：`marguerite:heavy_machinery_block`（重型机械方块）、`energized_magic_block`（充能魔力块），
  见 `kubejs/startup_scripts/block/magic_machinery_blocks.js`。
- 贴图暂复用原版 / IE 贴图占位（`builder.texture()` / `textureAll()`），后续可替换为专属贴图。

**门槛改造**（沿用「高级电子元件解锁难机器」分级思路，见 08 文档）：

- 回转窑滚筒（`rotary_kiln_cylinder`）复合窑壁中心掺入 **高级电子元件**（`component_electronic_adv`）。
- 激发器（`create_new_age:basic_energiser`）合成追加 **高级电子元件**。
- 车窑砖（`car_kiln_brick`）中心由铜线圈改为 **重型机械方块**——重型机械方块门槛车窑。
- 斗轮挖掘机沿用 IE **重型工程块**（已由高级电子元件门槛），仅在任务链上串接，不额外改结构。

**第四章提前铺垫：挖掘机产锇**

- 注册旧地狱（`marguerite:old_hell`）专属矿物脉 `kubejs:ch3_old_hell_osmium_vein`
  （`immersiveengineering:mineral_mix`），主产 `mekanism:raw_osmium`（锇），副产硫粉。
- ⚠️ **世界生成注意**：旧地狱为 `minecraft:flat` 生成器且 `features: false`，IE 矿物脉世界特征
  默认**不会自然生成**，斗轮挖掘机可能采不到锇。落地时需二选一：
  1. 在 `kubejs/data/marguerite/dimension/old_hell.json` 打开 `features`（或改用带矿物脉的生成器）；
  2. 用 IE 命令 `/ie mineral set kubejs:ch3_old_hell_osmium_vein` 手动为区块指定矿脉。
- 详见「开放问题」。
