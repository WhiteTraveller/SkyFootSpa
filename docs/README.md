## 维护约定

- 目录结构：根层放总览/系统模块文档（00–05），章节设计文档按章节收入子目录（如 `第二章-沉浸工程/`，后续第三章起 `第三章-xxx/`）；章节内文件名保留编号、不带章节前缀。
- 设计变更先更新本目录对应文档，再动代码。
- 每篇文档末尾保留「开放问题」小节，记录未决设计点。
- 进度快照以 [05-当前阶段与待办](05-当前阶段与待办.md) 为唯一事实来源。
